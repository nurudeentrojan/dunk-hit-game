# Dunk Hit - Basketball Game

A fun and addictive basketball shooting game inspired by the popular "Dunk Hit" mobile game!

## Features

🏀 **Realistic Basketball Physics**
- Gravity and friction simulation
- Ball bounce and collision detection
- Smooth trajectory mechanics

🎯 **Dynamic Gameplay**
- Moving hoop that gets faster as you progress
- Level progression system
- Combo multiplier for consecutive shots
- 3-miss limit before game over

📊 **Score System**
- Points increase with combo multiplier
- Best score tracking (saved in browser)
- Level difficulty increases with performance

🎮 **Intuitive Controls**
- Drag and release to aim and shoot
- Works on desktop (mouse) and mobile (touch)
- Visual drag indicator

📱 **Fully Responsive Design**
- Beautiful gradient UI
- Mobile-friendly interface
- Works on all screen sizes

## How to Play

1. Click "Start Game" to begin
2. Drag the basketball to aim
3. Release to shoot
4. Make the ball go through the hoop
5. Hoop moves faster with each successful shot
6. Get 3 misses and it's game over!
7. Try to beat your best score!

## Game Mechanics

### Scoring
- Base points: **10 points per shot**
- Combo multiplier: Points increase with consecutive hits
- Miss 3 times and game is over

### Difficulty
- Level increases every 3 consecutive shots
- Hoop speed increases as you level up
- Challenges scale with your performance

## Installation

1. Clone the repository:
